Installation

npm install routiva

Basic Usage

import { App } from 'routiva';

const app = new App();

app.use(App.logger());
app.use(App.json());

app.get('/health', (req, res) => res.json({ status: 'ok' }));

app.get('/users/:id', (req, res) => {
  res.json({ id: req.params.id, query: req.query });
});

app.post('/users', (req, res) => {
  res.status(201).json({ created: req.body });
});

app.listen(3000, () => console.log('http://localhost:3000'));

Core Concepts

The five ideas that carry the whole design

01

App extends Router

App is a Router plus server lifecycle, settings and default responses.

02

Everything is a layer

Routes, middleware and error handlers live in one ordered stack.

03

next(err) controls flow

Handlers either respond or call next(). next(err) enters error mode.

04

Raw objects wrapped

IncomingMessage/ServerResponse become Request/Response classes.

05

Zero dependencies

Only Node built-ins: http, url, fs, zlib, path, crypto.

Architecture

Understand how routiva works under the hood

Request Lifecycle

Client → App._handle → wrap req/res → Router.handle → dispatch(stack)
  → middleware/route (may call next or respond) → done(err)
  → _handleError (500) or _handleNotFound (404/405/OPTIONS)

Key Invariants

  • Order of registration = execution order
  • A layer may respond and may call next(); responses write-once
  • Errors flow to 4-arity handlers (length === 4)
  • Both throw and Promise.reject reach error middleware
  • HEAD reuses GET; OPTIONS/405 handled automatically

Examples

See routiva in action

CRUD App Example

A complete CRUD API demonstrating routing, body parsing, and error handling.

import { App } from 'routiva';
const app = new App();

app.use(App.json());

let items = [];
let id = 1;

app.get('/items', (req, res) => res.json(items));
app.post('/items', (req, res) => {
  const item = { id: id++, ...req.body };
  items.push(item);
  res.status(201).json(item);
});
app.get('/items/:id', (req, res) => {
  const item = items.find(i => i.id == req.params.id);
  if (!item) return res.status(404).json({ error: { message: 'Not Found' } });
  res.json(item);
});

app.listen(3000);

Mounted Router

import { App, Router } from 'routiva';

const app = new App();
const api = new Router();

api.get('/status', (req, res) => 
  res.json({ status: 'ok' })
);

app.use('/api', api);
app.listen(3000);

Error Handling

import { App, HttpError } from 'routiva';

const app = new App();

app.get('/boom', () => {
  throw new HttpError(500, 'Something went wrong');
});

app.use((err, req, res, next) => {
  res.status(err.status || 500).json({
    error: { message: err.message }
  });
});

app.listen(3000);
