Reference

API reference

The complete export list, the App and Router classes, the Request and Response surface, and every middleware factory signature.

A single-page index of the public API. Each API area links to a page with more detail and examples.

Exports#

js
import App, {
  createApp, Router, Request, Response,
  HttpError, statusMessage, STATUS_TEXT,
  json, urlencoded, text, raw,
  logger, rateLimit, MemoryStore,
  serveStatic, cors, compress,
  sendFile, lookupMime,
} from 'routiva';
ExportKindPurpose
Appclass (also the default export)The application
createApp(options?)functionnew App(options)
RouterclassA mountable sub-router
Request / ResponseclassesThe wrapped req / res
HttpErrorclassAn Error with an HTTP status
statusMessage(code)functionCanonical reason phrase
STATUS_TEXTobjectThe status-code → reason-phrase map
json urlencoded text rawfactoriesBody parsers
loggerfactoryRequest logging
rateLimitfactoryFixed-window rate limiting
MemoryStoreclassThe default rate-limit store
serveStaticfactoryStatic file serving
corsfactoryCORS headers and preflight
compressfactorygzip / deflate / brotli
sendFilefunctionLow-level file sender
lookupMime(filePath)functionExtension → MIME type

Every middleware factory is also attached to the class, so you can write App.json(), App.cors(), App.serveStatic(), and so on.

App#

js
import { App, createApp } from 'routiva';

const app = createApp({ trustProxy: true });
// identical to: new App({ trustProxy: true })
MemberDescription
new App(options?)Create an app
app.listen(port, [host], [cb])Create/start the http.Server; returns it
app.close([cb])Stop the server; returns this
app.handle(req, res, done)Dispatch an already-wrapped request
app.set(key, value)Set a setting; returns this
app.setting(key)Read a setting
app.enable(key) / app.disable(key)Boolean setting helpers
app.get/post/put/patch/delete/head/options/allRoute registration
app.use([path], ...handlers)Middleware / mount a Router
app.param(name, fn)Parameter callback
app.route(path)Chainable method registration

App options#

OptionDefaultEffect
envprocess.env.NODE_ENV or 'development'Environment name
trustProxyfalsereq.ip / req.ips read X-Forwarded-For
xPoweredByfalseEmit X-Powered-By: routiva
jsonSpaces0Reserved
exposeStackenv !== 'production'5xx messages and stacks in responses

Settings are the same keys, read and written via app.setting() and app.set(). See Core concepts.

Errors#

js
import { HttpError, statusMessage, STATUS_TEXT } from 'routiva';

throw new HttpError(422, 'validation failed', { type: 'validation.failed' });
statusMessage(404);        // 'Not Found'
STATUS_TEXT[500];          // 'Internal Server Error'
HttpError memberDescription
new HttpError(status, message?, options?)options: expose, type, cause
.status / .statusCodeThe status code
.exposestatus < 500, or options.expose
.typeMachine-readable code, echoed in responses
HttpError.badRequest(message?, options?)400
HttpError.unauthorized(...)401
HttpError.forbidden(...)403
HttpError.notFound(...)404
HttpError.methodNotAllowed(...)405
HttpError.tooLarge(...)413
HttpError.internal(...)500

Utilities#

ExportDescription
sendFile(req, res, filePath, options?)Low-level file sender (used by res.sendFile and serveStatic)
lookupMime(filePath)Extension → MIME type, falling back to application/octet-stream
js
lookupMime('app.css');      // 'text/css; charset=utf-8'
lookupMime('photo.webp');   // 'image/webp'
lookupMime('archive.rar');  // 'application/octet-stream'

Default responses#

When nothing responds, routiva produces one of:

SituationResponse
No path matched404 + { error: { message, status: 404, path } }
Path matched, wrong method405 + Allow + JSON error
OPTIONS on a known path204 + Allow
Unhandled error4xx/5xx JSON error from _handleError
