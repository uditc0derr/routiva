The web framework you can read in an afternoon.

routiva gives you the Express ergonomics you already know — routing, middleware, body parsing, static files, CORS, compression and rate limiting — in about 1,900 lines of dependency-free JavaScript built directly on node:http.

Everything you reach for, without the graph of packages.

Each of these ships in the core. In Express, most of them are a separate install.

Routing

:params, * wildcards, router.route() and mounted sub-routers with prefix stripping.

Middleware

One ordered stack. Registration order is execution order, exactly like Express.

Body parsing

json, urlencoded, text and raw with size limits, strict mode and 413 handling.

Static files

serveStatic with ETags, ranges, caching and traversal protection. Plus res.sendFile.

CORS

Correct preflight handling, origin reflection with credentials, and Vary: Origin.

Compression

Brotli, gzip or deflate chosen from Accept-Encoding, with a size threshold.

Rate limiting

Fixed-window limiter with X-RateLimit-*, Retry-After and a pluggable store.

Logging

One line per request with method, URL, status and duration. Bring your own stream.

Safe by default

Async errors are caught automatically, duplicate sends are ignored, and 405/OPTIONS are correct.

Familiar API

Looks like Express. Reads like a book.

If you know Express, you already know routiva. Import App, register middleware and routes, and listen.

  • Named ESM exports and App.* statics
  • req.params, req.query, req.cookies, req.body
  • Chainable res.status().type().json()
  • Async handlers that reject into your error middleware

Stricter HTTP

Correct by default, not by convention.

routiva handles the awkward corners of HTTP that Express leaves to you.

  • 405 Method Not Allowed with a real Allow header
  • Automatic OPTIONS responses (204)
  • HEAD reuses GET routes with the body suppressed
  • Async throw and rejected promises reach error middleware
